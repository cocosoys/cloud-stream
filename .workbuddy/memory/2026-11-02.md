## 部署踩坑：gendb 拉不到 GitHub，jsdb 静默变空

**现象**：`deploy.ps1 -SkipBackend` 全绿，但 zip 从 1.16 MB 掉到 0.55 MB，
线上 `/jsdb/windows/045e-028e.json` 404 —— 1992 个手柄映射文件全没了。

**根因**：`selkies-web-core` 的 `postbuild` 是 `node gendb.js`，它要从
`api.github.com` + `raw.githubusercontent.com` 拉 SDL_GameControllerDB。本机现在
到 `raw.githubusercontent.com` TLS 握手就失败（13.8 s 后 `schannel: failed to
receive handshake`）。gendb 拉不到时不写任何文件、也不让构建失败 —— 于是
`vite build` 仍报成功，`copy-assets.js` 拷了 0 个文件，整个前端照样发上线。
`deploy.ps1` 又是先删 `core/dist` 再构建，所以上一次的 jsdb 也没了。

**当时的处置**：被控机 `C:/dev/selkies-web.prev`（上一版前端）里还留着完整
`jsdb`，远端 `tar -czf` 打包 → scp 拉回 → 解开到 `dashboard/dist/jsdb`
（1992 个文件：android 271 / ios 19 / linux 572 / mac 262 / windows 868）→
`deploy.ps1 -SkipBackend -SkipBuild` 重新打包，zip 回到 1.16 MB，线上 200。

**待定**：gendb 要不要在网络失败时 `exit 1`（宁可构建失败也不发残缺包）。
现在这种"静默降级 + 部署脚本先删旧产物"的组合，会让缺文件的上线看起来完全正常，
只看部署日志发现不了，只能比对 zip 体积或抽查 `/jsdb/**`。
