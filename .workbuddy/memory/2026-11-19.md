# 2026-11-19 · S4 第四轮实机验证 + 0.4.1 崩溃自愈

## 一句话

把 `game_autostart` / `exclusive` / `restart_max` 三项从"代码走通"变成"机器上走通"；
过程中确认主动停止恒为 `killed-window-gone`，据此加了 `last_exit.requested` 与崩溃自愈。

## 实测（`.128`，0.4.1）

| 场景 | 结果 |
|---|---|
| `game/stop` ×4（windowed ×3 + exclusive ×1） | 全部 `killed-window-gone` + `code=1` —— 形态而非偶发 |
| `display.model=exclusive` | 窗口 `1920×1080 @0,0`；windowed 是 `1936×1100 @0,0`（差 16×20 边框） |
| `game_autostart=true` + 重启计划任务 | 7 s 后自动 start，200 s 出窗口，`armed=true reason=autolock` |
| `restart_max=2` + 强杀 javaw ×2 | 都自愈，`restarts` 1→2，pid 4400→5280→5424 |
| 第 3 次强杀 | 停在 `stopped`，`restarts` 不涨 |
| 主动 stop（配额未用尽） | `requested=true`，25 s 后仍 stopped、`restarts=0` |

冷启动耗时 130–200 s（5 mod + CustomNPCs Markov 字典），比想象慢，面板"启动中…"要撑得住。

## 代码（0.4.1，提交 89dbb3f）

* `Exit.requested`：`stop()` 写 true，`status()` 收尸写 false。
* `should_restart()`：`max>0 && !requested && code!=0 && restarts<max`，纯函数好测。
* `spawn_supervisor`：2 s 轮询 + `at_unix` 去重 + 重启后补 autolock。
* `start`/`start_inner`：手动起归零配额，自愈起消耗。
* 单测 512（+6）。

## 会话隔离（重要，别再踩）

SSH 登录在 **Session 0**，游戏窗口在 **Session 1**。所以 `FindWindow('LWJGL')`、
`GetWindowRect`、`Process.MainWindowHandle` 在 SSH 里全是空/0 ——
不是窗口不存在，是看不见。判断窗口一律用服务端的 `health.game.window`。

## 远端 PowerShell 5.1 的规矩

* 脚本必须 **UTF-8 with BOM**，否则中文注释按 GBK 解会破坏引号配对（报
  `意外的标记 }`）。
* `ScriptBlock → 委托`（`EnumWindows` 回调）里给 `$script:` 赋值不生效，
  枚举"成功"但结果恒 0。改用 `FindWindow` 或让服务端给句柄。
* 本地 PowerShell 传参给 `ssh` 时，命令含 `|` 会被本地解析 → 用单引号包整条
  （PowerShell 会自动加双引号，远端 cmd 就不再解析管道）。
