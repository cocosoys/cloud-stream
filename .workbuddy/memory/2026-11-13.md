### 发现并修掉的交付缺口

`toolchain/stream-config.toml`（整包自带、用户会直接编辑的那份）**没有
`pointer_recenter`** —— 它只出现在 `--print-config` 输出里。#124/B 默认 false，
想开的人翻配置看不到键，只会以为没这功能。提交 `b5294de` 补上。

机械核对了模板 vs `--print-config` 的键集合：25 vs 33，差的八个是
`auth_token` / `tls_cert` / `tls_key` / `log` / `dump_frame` / `upload_dir`（空串项，
模板有意省略）+ `dist`（启动推导）+ 这一项。**结论：模板是"常态可编辑项"的裁剪版，
不是全字段镜像，别整体同步，只补布尔/非空的新项。**

### 坑：PowerShell 抓 GUI 子系统的 stdout 会吞换行

`& exe --print-config | Out-File` 出来 63 行、注释和 `key = value` 粘成一行 ——
PowerShell 按 GBK 解码 UTF-8 输出，多字节序列错位把 `\n` 一起吃掉了。**不是 exe 的
bug**。要拿原始输出用 bash 重定向：`./stream-server.exe --print-config > /tmp/pc.toml`
（101 行、33 键）。同理 `--diagnose` 的正文要从落盘文件读，别读管道。

### 三个坑（都写进了 docs/deploy-notes-mc-coexist.md 第六节）

1. **ssh 落 session 0**，在那儿起的 java 窗口不属于任何看得见的桌面：进程活着、
   日志写到 `Narrator library loaded`、CPU 也在动，屏幕就是没有。得用
   `schtasks /IT` 投进 console 会话（`query session` 能看到 `console Admin 1 运行中`）。
2. **`-WindowStyle Hidden` 的 `SW_HIDE` 会被第一个窗口继承**。MC 只有一个 LWJGL
   窗口 → 窗口存在但 `vis=False`、尺寸 1x1，游戏在后台完美运行。用 `javaw.exe`
   即可，别再叠 Hidden。
3. **带中文注释的 .ps1 必须存成 UTF-8 with BOM**。5.1 按 GBK 读无 BOM 文件，注释
   字节错解后吞掉换行，`param` 整块解析失败，报"第 24 行 意外的标记 )" —— 像语法
   错，其实是编码。`EF BB BF` 一加就过。

另外 `schtasks /TR` 不解释 `>` 重定向、上限 261 字符；要日志让脚本自己写文件。

### 验证截图的办法

跨会话截不到别会话的画面，所以把截屏脚本也投递进去；脚本要先
`ShowWindow(GetConsoleWindow(), SW_HIDE)` 藏掉自己的黑窗口 —— 否则它会正正挡在
游戏前面（踩了两轮才发现是自指）。`win: 5768 | 870x519 | Minecraft 1.12.2`
出现在 `C:\mc\shot.txt` 就是成了。
