## #101 滚轮向上无效 + 产物文档同步

- 症状：滚轮上滑无反应，下滑正常。根因：`sync_scroll` 的 `SCROLL_BITS = 0b1100_1000` 只含 bit 7/6/3，**漏 bit 4（向上）**；差分后 bit4 恒 0 → 上滚永远没有上升沿，一个 WHEEL 事件都不注入。方向表本身是四条（含 bit4），所以两边不一致看不出异常，注入还"成功"。
- 修法：`SCROLL_BITS = 0b1101_1000`；抽纯函数 `scroll_pulses(prev, mask, mag) -> Vec<(bool, i32)>`，`sync_scroll` 只负责注入，使位表可在不碰 SendInput 下断言。
- 回归：`scroll_edges_cover_both_vertical_directions`（常量钉成 `1<<3|1<<4|1<<6|1<<7`，旧值必挂；逐方向符号；mag=0 兜底 1）、`a_scroll_pulse_fires_once_between_clear_and_release`（cleared→set→restored 三条只中间注入）。
- 前端契约核对：`_triggerMouseWheel` up→bit4 / down→bit3（`input.js:4692`），`_triggerHorizontalMouseWheel` left→bit6 / right→bit7（`:4711`），与服务端一致。
- 验证：`cargo test -p stream-server` 161 passed / 0 failed / 1 ignored；全量部署 pid 9504，health `streaming`。
- 产物现状（2026-11-03 全量部署 495.6 s）：exe 18,603,008 B、ViGEmClient.dll 140,288 B、zip 1,214,640 B、dist 2008 文件（清单 2007 + 自身）、清单 3,275 B / 3,778,871 B、jsdb 1994（win868/linux574/android271/mac262/ios19）。
