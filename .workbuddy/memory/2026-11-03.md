## #101 滚轮向上无效 + 产物文档同步

- 症状：滚轮上滑无反应，下滑正常。根因：`sync_scroll` 的 `SCROLL_BITS = 0b1100_1000` 只含 bit 7/6/3，**漏 bit 4（向上）**；差分后 bit4 恒 0 → 上滚永远没有上升沿，一个 WHEEL 事件都不注入。方向表本身是四条（含 bit4），所以两边不一致看不出异常，注入还"成功"。
- 修法：`SCROLL_BITS = 0b1101_1000`；抽纯函数 `scroll_pulses(prev, mask, mag) -> Vec<(bool, i32)>`，`sync_scroll` 只负责注入，使位表可在不碰 SendInput 下断言。
- 回归：`scroll_edges_cover_both_vertical_directions`（常量钉成 `1<<3|1<<4|1<<6|1<<7`，旧值必挂；逐方向符号；mag=0 兜底 1）、`a_scroll_pulse_fires_once_between_clear_and_release`（cleared→set→restored 三条只中间注入）。
- 前端契约核对：`_triggerMouseWheel` up→bit4 / down→bit3（`input.js:4692`），`_triggerHorizontalMouseWheel` left→bit6 / right→bit7（`:4711`），与服务端一致。
- 验证：`cargo test -p stream-server` 161 passed / 0 failed / 1 ignored；全量部署 pid 9504，health `streaming`。
- 产物现状（2026-11-03 全量部署 495.6 s）：exe 18,603,008 B、ViGEmClient.dll 140,288 B、zip 1,214,640 B、dist 2008 文件（清单 2007 + 自身）、清单 3,275 B / 3,778,871 B、jsdb 1994（win868/linux574/android271/mac262/ios19）。

## 访问口令 --auth-token（d9e78b5）

- 用户要求先落地两项：硬件编码（NVENC/VAAPI）、登录/鉴权口令。先做鉴权 —— 不依赖硬件，且是真实欠账（Principal 只带 peer，Credential 恒为 None，策略 allow-all）。
- 关键发现：前端契约早已完整，服务端是缺的那条腿。`selkies-web-core/lib/session-token.js` 实现五种载体（fragment / query / Bearer / cookie `selkies_token` / WS subprotocol `selkies.token.<b64url>`）；`auth-guard.js` 用 `WWW-Authenticate: ^Bearer realm="Selkies` 区分令牌 401（不重载，重载还是同一个令牌）与 Basic 墙（重载才能重新登录）。少了这个头，输错口令的页面每 30 秒自刷且永远好不了。
- 实现：`security/token.rs`（TokenGate + 常量时间比较 + 四载体提取，`principal()` 复用 `Principal::from_peer`）、`config.rs` 加 `--auth-token`（空串=关闭）、`http/server.rs` 口令判定放在策略**之前**（没凭据不该先读到 403）、`main.rs` 每次启动写一行开/关状态（"没开"与"开了但没带 token"在浏览器里都是一片空白，这两行是唯一区分点）。
- 豁免 Static 与 Status：前端 bundle 是 MPL 开源无秘密，且页面必须能开，否则用户看不到"这机器要口令"（正是上一轮花力气消掉的"启动了没效果"）；status 正文只有 ok，部署脚本与探针都靠它。
- **连带修掉一个会自己制造的假警报**：probe-listen.cmd 与 setup-watchdog.bat 原探 `/api/v1/health`，而 health 现在受口令保护 → 每台设了口令的机器都会打印 `PREFLIGHT NOT listening` / `[fail]`。两处改探 `/api/status`（问"端口有人应答吗"，不是"管道健康吗"），文案 `local health 200` → `local status 200`。
- 上机脚本：口令放 `auth-token.txt`，由 start-stream.cmd/.60fps.cmd 用 `for /f` 读（`set /p` 读不到无结尾换行的文件；`echo ?token=<token>` 里的 `<` 会被 cmd 当输入重定向）。新增 `set-password.cmd`，写入交给 PS 子进程（`echo %PW%` 在 `& | < >` 和空口令上静默失败），强制 ASCII（cmd 边界）。打包/安装列表 8→9。
