## 修掉 `http::health` 的偶发 stalled 误判（7c8ce5d）

- 症状：`a_live_pipeline_reports_streaming` 满负荷并行跑 5 次挂 2 次，隔离 3/3 通过。
- 根因：`build()` 里每个 age 各自 `Instant::now()`，测试线程被挂起 >3 s 时「刚写过」与「重新取的 now」之间凭空多出 3 s → 健康管线报 stalled。生产路径同缺陷：streaming/stalled 与 starting/no_first_frame_after_15s 用不同参考点。
- 改法：抽出 `build_at(cfg, probe, sample, session, now)`，`build()` 退化为 `build_at(..., Instant::now())`；`snapshot_fields(&g, now)`、`connected_at` 的 waited/connected_s 全用传入 `now` + `saturating_duration_since`。
- 新测试 `the_verdict_is_computed_against_the_supplied_instant`：同一快照把读取时刻推后 4 s 必须判 stalled，旧实现过不了这条。
- 验证：`cargo test -p stream-server` 连跑 3 次 159 passed / 0 failed / 1 ignored。
