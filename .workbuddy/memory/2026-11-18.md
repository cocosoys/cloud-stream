### 脚本要点

`/XJ` 关键（源里可能自带 junction，跟着走会重复甚至成环）；
删 junction 必须用 `[IO.Directory]::Delete`（`Remove-Item -Recurse` 会穿进目标删真文件）；
`client_dir` 只替换捕获段，不走 `ConvertFrom-Json` 往返（会重排键、改转义）。

### 工程坑

- **Bash heredoc 里的反斜杠会被工具链改造**：`r"C:\Users"` 落到文件里变成
  `C:/Users`，`\\\\` 变成 `////`。写 Windows 路径的夹具/文件一律用 Write 工具或
  PowerShell，别用 bash heredoc + python。
- `build.ps1 -Task test` 编译超过工具默认 120 s 会被截断并返回 exit 1，
  看起来像编译失败（实际是超时）；重跑或加大 timeout 即可。曾误判为
  LNK1104「目标 exe 被占用」。
